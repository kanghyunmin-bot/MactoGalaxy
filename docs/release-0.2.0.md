Galaxy Tab을 Mac의 터치 가능한 확장 디스플레이로 사용하는 0.2.0 시험 릴리스입니다.

- 2560×1600 / 1920×1200 확장 화면, HEVC/H.264, 60Hz 목표.
- Galaxy 전체 화면과 Mac 터치 조작.
- USB 자동 텍스트 공유, 수동 사진·파일 공유(항목당 24MiB).
- 새 앱 아이콘, 키체인 대기 중 창 표시, 연결·화면 복구 개선.
- 이전 미러링·HID·전용 입력기 제거.

설치: macOS 14+는 DMG의 앱을 응용 프로그램에 복사하고 ADB를 설치하세요 (`brew install android-platform-tools`). 화면 기록과 손쉬운 사용 권한이 필요합니다. Android 12+는 APK를 설치하세요. 기존 개발 APK와 서명이 다르면 업데이트 설치가 불가능합니다. 기존 데이터를 삭제하기 전에 백업하세요.

Mac 앱은 개발 서명이며 Apple 공증이 없습니다. 가상 디스플레이에 macOS 비공개 API를 사용합니다. Intel 빌드는 교차 빌드이며 실기기 검증은 Apple Silicon Mac과 SM-X930에서 진행했습니다. 텍스트/화면/터치 일부 실기기 검증과 자동 검증을 통과했으며, 사진·파일 양방향 실전송과 지속 60fps·다기종 검증은 남아 있습니다. 전송 암호화를 제공하지 않습니다.

첨부: macOS 유니버설 DMG, Android release APK, SHA256SUMS.txt. 자동 텍스트 공유에 사용하는 고정 버전 scrcpy 서버와 라이선스는 Mac 앱에 포함되어 있습니다.
